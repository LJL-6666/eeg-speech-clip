# Stage 3 设计说明（CLIP 风格跨模态对比学习）

## 方法概要

- **语音端**：预训练编码器冻结；可选 Whisper / Wav2Vec2-XLS-R-300M / mHuBERT-147；末端 Linear → 128 维。
- **EEG 端**：EEGNet + Linear → 128 维；窗口 4 s、步长 2 s；**不做额外 1–8 Hz 带通**（仅重采样 + 通道 z-score）。
- **损失**：对称 InfoNCE；L2 normalize 后余弦相似度；learnable temperature；**无额外 L2 正则**。
- **素材键**：`speaker_id + emotion` → `material_key`，再与 `window_idx` 组成 `pair_key`。
- **划分**：leave-one-material-out（52 fold）；`UniquePairKeyBatchSampler` 避免同 batch 内重复 pair_key。
- **评估**：Speech→EEG / EEG→Speech 的 top1、top5；matched vs video-shift / time-shift 控制。

## 与 Stage 1/2 的区别

| | Stage 1/2 (TRF) | Stage 3 (本目录) |
|---|----------------|------------------|
| 目标 | 语音特征能否**预测** EEG 时间序列 | EEG 与语音能否在共享空间**对齐/检索** |
| 语音 | Whisper PCA + 时滞 ridge | 冻结 encoder + 投影 |
| EEG | 常配合 1–8 Hz | 全频段最小预处理 |
| 主指标 | 留出视频 Pearson r | Retrieval top1/top5 |

黎明建议：在 TRF 已见弱稳定效应后，以 CLIP 对比学习为主结论路线；不必再强调 envelope 控制 Whisper。

## CLIP vs CLAP

二者均为对称 InfoNCE。CLAP 常用更大 batch 与 learnable temperature。本实现采用 **CLIP 经典流程 + learnable temperature**，不引入 CLAP 的额外结构。

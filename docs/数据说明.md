# 数据说明

## EEG 输入（communication 任务）

| 路径（本项目中） | 实际位置 | 说明 |
|------------------|----------|------|
| `data/eeg_original` | `Preprocessing/output/communication` | 120 被试 × 28 trials，历史分析默认 |
| `data/eeg_corrected` | `Preprocessing/output/communication_corrected_20260519` | 108 原版 + 12 修正 pkl |

### 修正被试（12 人）

`024, 026, 033, 035, 036, 039, 042, 051, 096, 112, 122, 135`

- 修正内容：raw BDF **begin timestamp** 对齐，trial 数不变（仍为 28）。
- 未纳入：`018, 019`（需人工复核）。
- 清单文件：`data/corrected_subjects.txt`

### 修正来源与 QC

- 隔离试验目录：`data/raw_bdf_begin_timestamp_correction/`
- 修正后 pkl：`.../isolated_corrected_output_begin_ms/communication/`
- QC 表：`.../qc/isolated_corrected_run_summary_begin_ms.csv`

## Whisper 特征（Stage 3 whisper 后端）

- `data/stage1_audio_whisper_embeddings_v2/`（软链接至 `EEG/data/...`）
- 运行参数：`--speech-source existing-whisper`

## Wav2Vec2 / HuBERT 帧级缓存

- 目录：`cache/speech_features/<backend>_<model>/win4.000_stride2.000/`
- 由 `--prepare-speech-cache` 生成；与 EEG 根目录无关，**原版与修正版可共用同一语音缓存**（同一刺激音频）。

## 实验元数据

- `experiments/stimulus_narrative_v1/narrative_identity.csv`（软链接至 `EEG/experiments`）
- 用于 `video_id → speaker + emotion` 映射。

## 训练时指定数据版本

```bash
# 原版（默认）
python code/stage3_speech_eeg_clip.py --eeg-root data/eeg_original ...

# 修正版
python code/stage3_speech_eeg_clip.py --eeg-root data/eeg_corrected \
  --run-name clip_wav2vec2_corrected_full ...
```
